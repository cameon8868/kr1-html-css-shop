# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный интернет-магазин техники TechnoShop.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — карточка товара;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — каталог, фильтры и формы;
- `js/products.js` — данные товаров и отзывы;
- `js/product.js` — логика страницы товара;
- `js/shop.js` — корзина и переключение темы;
- `js/consultant.js` — автоматический консультант;
- `image/` — изображения товаров и логотип;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.
## Используемые технологии

- HTML;
- CSS;
- Git;
- GitHub.

## Текущий статус

Реализован адаптивный многостраничный интернет-магазин с каталогом, карточками товаров и оформлением заявок. Серверной части и подключения к реальному оператору нет.

## Возможности сайта

- поиск по названию и описанию товаров;
- фильтрация по категории, диапазону цены, популярности и новинкам;
- сортировка по цене и названию;
- карточки товаров с характеристиками, отзывами и похожими товарами;
- корзина с изменением количества товаров и сохранением в браузере;
- форма заявки с валидацией;
- переключение светлой и тёмной темы с сохранением выбора;
- автоматический консультант с ответами на частые вопросы и ссылками на разделы сайта;
- адаптивная вёрстка для телефонов и небольших планшетов.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- форму оформления заявки в модальном окне;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `site-footer` — подвал и навигация сайта;
- `consultant` — виджет автоматического консультанта;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка.

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.
